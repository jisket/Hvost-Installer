# Хвост — установщик Windows


[Скачать один CMD](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.3-alpha.1-pilot.20261107/Hvost-Install.cmd)


1. Сохраните `Hvost-Install.cmd` в отдельную обычную папку и запустите двойным щелчком. ZIP и ручное скачивание EXE не нужны.
2. Дождитесь загрузки и проверки клиента. Подтвердите показанную рабочую папку. Кабинет откроется в браузере автоматически.
3. Войдите в свой аккаунт. Выберите **Компьютеры → Подключить компьютер** и вставьте полученный **16-символьный код подключения** в окно CMD. Это другой код, чем код входа в кабинет.


Оставьте окно открытым во время работы. Для повторного запуска используйте тот же CMD в той же папке: профиль и рабочие файлы сохраняются. Закрытие окна или Ctrl+C останавливает клиент. Папки `profile` и `workspace` не удаляйте.


Предварительная версия **0.8.3-alpha.1**, Windows 10/11 x64. Только чтение и запись в `workspace`, без автозапуска и дополнительных полномочий. Существующий тестовый владелец использует прежний аккаунт. В кабинете включена регистрация новых пользователей по логину и паролю. Для второго ПК существующего тестового владельца выберите вход в прежний кабинет: новый аккаунт получит отдельный бесплатный тариф.


Клиент пока без подписи издателя. Результат проверки Касперским и приёмка второго физического ПК не подтверждены. Если защита блокирует файл, остановитесь и сохраните название обнаружения. Не отключайте антивирус и не добавляйте исключения.


CMD загружает EXE только из конкретного выпуска GitHub и проверяет его размер и SHA256 перед каждым запуском. При повреждении файла запуск прекращается. Паролей, ключей, серверного кода и данных аккаунтов в этом репозитории нет.
