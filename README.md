# Хвост — Windows-клиент

Подключайте свой компьютер к своему аккаунту. Этот репозиторий содержит только тестовые установщики, без серверного кода и данных пользователей.

## Установить заново

[Скачать Hvost-Reinstall.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.6-alpha.1-pilot.20261107/Hvost-Reinstall.cmd) — скачайте только этот файл на нужный ПК и запустите.

1. Закройте прежнее окно управления Хвост.
2. Просмотрите пути в CMD и лично введите REINSTALL. Старый клиент будет остановлен, прежние файлы сохранятся.
3. В открывшемся кабинете войдите в существующий аккаунт, нажмите «Подключить компьютер», получите код и вставьте в CMD. Новый профиль и карточка будут созданы в том же аккаунте.
4. Готово: используйте ярлык «Хвост» на рабочем столе. CMD можно закрыть.

Старую карточку сначала отключите, затем нажмите «Удалить из кабинета». История сохраняется; «Показать удалённые компьютеры» позволяет вернуть карточку без восстановления доступа. Старые profile/workspace на диске не удаляются.

Начальные права — чтение и запись в рабочей папке. Остальные инструменты выбираются отдельно для каждого ПК в кабинете и требуют личного подтверждения на ПК.

## Другие варианты

- [Первая установка — Hvost-Install.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.6-alpha.1-pilot.20261107/Hvost-Install.cmd). Новый пользователь регистрирует собственный логин/пароль; повторный вход использует существующий аккаунт.
- [Переподключение с сохранением ID — Hvost-Reconnect.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.6-alpha.1-pilot.20261107/Hvost-Reconnect.cmd). В кабинете выберите прежний ПК и получите код восстановления.
- [Полное управление подключённым ПК — Hvost-Control.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.6-alpha.1-pilot.20261107/Hvost-Control.cmd). Запустите в прежней папке клиента; нужен личный просмотр и FULL.

CMD сам скачивает точный EXE из GitHub и проверяет размер и SHA256. Фоновая работа начинается после согласия владельца; ярлык позволяет проверить соединение, остановить/запустить клиент и удалить клиент с сохранением данных.
