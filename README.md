# Хвост — один установщик для Windows

## [Скачать Hvost-Install.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.8-alpha.1-pilot.20261107/Hvost-Install.cmd)

**Скачайте только этот CMD и запустите на нужном компьютере.** EXE он скачает сам с GitHub, проверит размер и SHA256 и запустит мастер. Отдельные Control, Permissions, Reconnect и Reinstall скачивать больше не нужно.

### Если Хвост уже установлен

Откроется управление прежним компьютером. Установщик находит клиент по проверенному ярлыку «Хвост»; если ярлык отсутствует, запустите CMD из прежней папки установки.

Нажмите **«Права и обновление» → «Применить»**. Проверьте показанные возможности и подтвердите действие лично на этом ПК. Аккаунт, подключение, файлы и выбор автозапуска сохраняются. Новый код подключения не нужен.

### Если это новый компьютер

1. Просмотрите запрашиваемые права и подтвердите подключение.
2. В автоматически открытом браузере войдите в свой аккаунт или создайте логин и пароль.
3. Нажмите «Подключить компьютер» и вставьте полученный код в CMD.
4. При необходимости лично подтвердите запрос администратора Windows. Отказ не мешает обычному управлению.
5. После завершения используйте ярлык **«Хвост»**. Постоянно держать CMD открытым не требуется.

Новая установка предлагает обычные инструменты управления: файлы, терминал и программы, экран и ввод, браузер, установленные и настроенные Codex/Claude. Доступ ограничен правами вашей учётной записи Windows и подтверждёнными настройками.

### Всё управление в одном окне

Через ярлык или тот же CMD доступны проверка соединения, запуск и остановка, автозапуск, рабочая папка, кабинет, **права и обновление**, **восстановление связи**, **переустановка** и удаление клиента.

- «Восстановить связь» использует код восстановления прежнего компьютера из кабинета.
- «Переустановить» требует отдельного подтверждения REINSTALL; старые данные сохраняются, создаётся новое подключение в выбранном аккаунте.
- Если файлы или ярлык были изменены, установщик остановится для проверки и не перезапишет их.

В кабинете можно переключать уже подтверждённые инструменты. Новые локальные полномочия требуют подтверждения владельца на самом ПК. Администратор использует UAC и защищённый список задач; произвольные повышенные команды не разрешаются.
