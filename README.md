# Хвост — тестирование установщика приостановлено

**Не устанавливайте и не обновляйте клиент до 0.8.11.**

08.11.2026 Касперский удалил процесс клиента с обнаружением `PDM:Trojan.Win32.Generic`. MD5 из отчёта совпал с опубликованным EXE. Ложное срабатывание пока не подтверждено; проводится проверка.

Не отключайте защиту, не добавляйте исключения и не восстанавливайте файл из карантина для повторного запуска. Если клиент перестал отвечать после обновления, не переустанавливайте его и не создавайте новый компьютер: требуется сверка прежней операции и сохранённых данных.

Версия 0.8.11 выведена из каталога обновлений меткой `suspended-`. Исходные файлы сохранены без пересборки и замены только для анализа. Старый CMD этой версии больше не является действующим установщиком. Рекомендация предыдущей версии в качестве обхода блокировки не выдаётся.

- SHA256 EXE: `e38e9cad6143f39388b250ef401a67542a1842d2e9b19b90bac08b7fea0864db`
- MD5 EXE: `32c0b4d6065f92cd7f369ef928671c23`
- Подпись издателя: отсутствует.
- [Статус проверки и сохранённый выпуск](https://github.com/jisket/Hvost-Installer/releases/tag/suspended-v0.8.11-alpha.1-pilot.20261108).

Проект продолжает разрабатываться: один CMD, установка на системный диск, локальный ярлык, управление правами и Git-проектами. Инструкции установки будут возвращены после проверки и разрешённого возобновления испытаний. Проверки исходников и локальные тесты не заменяют антивирусную проверку и реальную приёмку. Полный релиз Windows/Linux не готов.
