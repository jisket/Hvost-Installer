# Хвост — Windows-клиент

Подключайте свой компьютер к своему аккаунту. Здесь находятся только тестовые установщики, без серверного кода и данных пользователей.

## Уже установлен Хвост

[Скачать Hvost-Permissions.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.7-alpha.1-pilot.20261107.2/Hvost-Permissions.cmd) — скачайте один файл на нужный ПК и запустите. Он сам загрузит проверенный EXE и найдёт прежний клиент по ярлыку.

В окне выберите права и нажмите «Применить». Новые возможности подтверждаются лично на этом ПК; для администратора дополнительно появится запрос Windows (UAC). Аккаунт, подключение и файлы сохраняются. Код подключения и новая регистрация не нужны.

Затем права можно менять через **ярлык «Хвост» → «Права доступа»** и **сайт → компьютер → «Изменить права»**. Уже подтверждённые инструменты переключаются без переподключения. Сайт не может самостоятельно выдать новые локальные полномочия.

## Первая установка

[Скачать Hvost-Install.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.7-alpha.1-pilot.20261107.2/Hvost-Install.cmd).

1. Запустите CMD на своём компьютере и просмотрите права и папки.
2. В открывшемся кабинете создайте собственный логин/пароль или войдите в существующий аккаунт.
3. Получите код через «Подключить компьютер» и вставьте его в CMD.
4. Подтвердите запрос Windows для административных возможностей, если они нужны. При отказе обычное управление продолжит установку.
5. Пользуйтесь ярлыком «Хвост». Постоянно держать CMD открытым не требуется.

Новая установка предлагает чтение и изменение разрешённых файлов, терминал/процессы, экран/ввод, браузер и доступные на ПК Codex/Claude. Административный помощник использует защищённый фиксированный список задач: в комплекте предусмотрена проверка личности `identity`, а произвольные повышенные команды не разрешены. Настоящая положительная проверка UAC на втором ПК ещё не завершена.

## Восстановление

- [Hvost-Reconnect.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.7-alpha.1-pilot.20261107.2/Hvost-Reconnect.cmd) — восстановить доступ к прежней карточке с кодом восстановления из кабинета.
- [Hvost-Reinstall.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.7-alpha.1-pilot.20261107.2/Hvost-Reinstall.cmd) — чистая установка после личного подтверждения REINSTALL; прежние данные сохраняются, потребуется новый код подключения в том же аккаунте.
- [Hvost-Control.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.7-alpha.1-pilot.20261107.2/Hvost-Control.cmd) — то же окно выбора прав.

Старую карточку можно отключить и убрать из кабинета с сохранением истории. Ярлык позволяет проверить соединение, остановить/запустить клиент и удалить его с сохранением данных.

## Статус

Тестовая версия 0.8.7-alpha.1, исправленный комплект №2. Загрузки разных версий хранятся отдельно по SHA256: старые файлы не мешают обновлению и не перезаписываются. CMD проверяет размер и SHA256 EXE перед запуском.

Версия без подписи издателя. Результат Касперского для текущего комплекта и полная независимая приёмка пока не подтверждены. Не отключайте защиту и не добавляйте исключения. Это не финальный публичный релиз продукта.
