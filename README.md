# Хвост — установщик Windows

[Скачать Hvost-Install.cmd 0.8.27](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.27-alpha.1-pilot.20261111/Hvost-Install.cmd) · [Все файлы выпуска](https://github.com/jisket/Hvost-Installer/releases/tag/v0.8.27-alpha.1-pilot.20261111)

Откройте CMD и выберите **1** — установить/открыть, **2** — полная переустановка, **3** — подключить или исправить Codex, **0** — отмена. Все подтверждения мастера цифровые.

Пункт3 для уже подключённого0.8.25 сохраняет клиент, устройство и аккаунт; сам штатно закрывает свободное окно управления. Занятое окно и работающие задачи не завершаются принудительно. Программу и аккаунт Codex пользователь просматривает лично.

При ошибке рядом с CMD остаётся отчёт Hvost-Install-Report-….txt. Резервные файлы при полной переустановке сохраняются отдельно; Codex и сторонние приложения не очищаются.

Ручная тестовая версия без подписи издателя. HTTPS, размер и SHA256 проверяются; SHA256 не удостоверяет издателя. Windows UAC и антивирус остаются включёнными по настройкам пользователя. Автоматической замены неподписанного клиента нет. Полный релиз Windows/Linux, работа до входа в ОС и приёмка на втором компьютере ещё не завершены. Приостановленный0.8.11 не устанавливайте.
