# Хвост — тестовый установщик Windows

Актуальный ручной тестовый выпуск: **0.8.23-alpha.1**.

## Установить на свой компьютер

1. [Скачать Hvost-Install.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.23-alpha.1-pilot.20261111/Hvost-Install.cmd) и запустить. EXE загружается автоматически; рядом со скриптом другие файлы не нужны.
2. Введите INSTALL, просмотрите права и подтвердите установку. Клиент устанавливается на системный диск и создаёт ярлык «Хвост».
3. В открывшемся кабинете войдите в свой существующий аккаунт и выберите «Подключить компьютер». Новый аккаунт для второго ПК не требуется.
4. Если установщик предложит подключить уже установленный Codex, проверьте аккаунт и рабочую папку и подтвердите. ChatGPT сможет запрашивать свежий список задач, включая архив, и продолжать выбранную задачу по исходному ID в разрешённой папке.

После установки CMD можно закрыть. Управление, проверка связи и удаление доступны через ярлык «Хвост». Если сохранились настройки удалённого клиента, установщик предложит восстановление или чистую переустановку с сохранением файлов.

## Статус тестирования

Клиент и продолжение существующей задачи через приложение ChatGPT проверены на одном Windows-ПК. Проверка второго ПК и антивируса ещё предстоит. Это тестовая версия без подписи издателя; она не включает неподписанное автообновление. Оставьте антивирус включённым. Полный релиз Windows/Linux ещё не принят.
