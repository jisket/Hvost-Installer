# Хвост — один установщик для Windows

## [Скачать Hvost-Install.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.11-alpha.1-pilot.20261108/Hvost-Install.cmd)

**Скачайте только CMD и запустите на нужном компьютере.** Он сам скачает клиент с GitHub и проверит размер и SHA256. Отдельные установщики для обновления, прав и восстановления не нужны.

### Где устанавливается клиент

Новый клиент устанавливается в `%LOCALAPPDATA%\Hvost\Client` на системном диске — обычно `C:\Users\<имя>\AppData\Local\Hvost\Client`. Кэш установщика хранится отдельно в `%LOCALAPPDATA%\Hvost\Installer`.

Скачанный CMD можно хранить в «Загрузках» и удалить после установки. Работа клиента от этой папки не зависит. Прежние установки сохраняют свою папку, аккаунт, файлы и подключение.

### Если Хвост уже установлен

Запустите новый CMD один раз: откроется управление прежним компьютером. Нажмите **«Обновить»**, затем **«Применить»** в локальном мастере. Проверьте показанные права и путь Codex; подтвердите действие лично на этом ПК. Новый аккаунт и код подключения не нужны.

Дальнейшие обновления доступны через ярлык **«Хвост» → «Обновить»**: новая версия скачивается прямо из окна клиента. Пока идёт проверка, текущий клиент продолжает работать.

**«Автообновление…»** включает проверку при входе вашей учётной записи в Windows. Тихая установка принимает только действующую подпись того же издателя. Текущий тестовый выпуск ещё не подписан: для него используйте кнопку «Обновить». Дополнительная постоянная служба обновлений не запускается.

### Если это новый компьютер

1. Просмотрите папку установки и запрашиваемые права.
2. В открывшемся браузере войдите в свой аккаунт либо создайте логин и пароль.
3. Нажмите «Подключить компьютер» и вставьте одноразовый код в CMD.
4. При необходимости лично подтвердите запрос администратора Windows. Отказ не мешает обычному управлению.
5. После завершения используйте ярлык **«Хвост»**. Держать CMD открытым не требуется.

Предлагаются файлы, терминал и программы, экран и ввод, браузер, установленные и настроенные Codex/Claude. Доступ ограничен подтверждёнными настройками и правами вашей учётной записи Windows.

### Codex и управление клиентом

Официальный Codex для Windows обнаруживается и без записи в PATH. Войдите в Codex обычным способом и примените права в «Хвосте». Клиент проверит подпись, версию и SHA256 программы; ключ или пароль установщику не нужны. Модель запускается только по заданию.

В окне доступны соединение, запуск/остановка, автозапуск, обновление, права, рабочая папка, кабинет, восстановление связи, переустановка и удаление. Восстановление использует код прежнего устройства. Переустановка требует отдельного REINSTALL и сохраняет старые данные. Изменённый профиль или ярлык не перезаписываются автоматически.

В кабинете можно переключать уже подтверждённые инструменты. Новые полномочия требуют личного подтверждения на ПК. Администратор использует UAC и защищённый список задач; произвольная повышенная командная строка не разрешается.

### Git-проекты из ярлыка

Откройте **«Хвост» → «Git-проекты…»**. Укажите папку существующего репозитория с первым коммитом, выбранный инструмент и команды тестирования/сборки. Если поля уже предложены, проверьте их.

Нажмите **«Проверить и показать обзор»**: мастер покажет точные программы, контрольные суммы и сценарии. После просмотра нажмите **«Применить»** и подтвердите подключение лично на этом ПК. Изменение поля требует нового обзора. Аккаунт и код привязки не нужны.

Задачи используют отдельные Git worktree. Применение проекта допускается только при отсутствии активной работы клиента; иначе сначала завершите её. Отзыв через «Отключить проект…» оставляет файлы и историю. Обновление прав сохраняет одобренные проекты.

Программы работают с правами вашей учётной записи Windows: это ещё не изолированная среда ОС. Не подключайте непроверенные команды и сценарии.
