# Хвост — установщик Windows

[Скачать Hvost-Install.cmd 0.8.31](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.31-alpha.1-pilot.20261113/Hvost-Install.cmd) · [Файлы выпуска](https://github.com/jisket/Hvost-Installer/releases/tag/v0.8.31-alpha.1-pilot.20261113)

Для запуска сохраните CMD в обычную локальную папку, например «Загрузки». Запуск непосредственно из облачных синхропапок в этой версии ограничен проверкой путей.

Откройте один CMD и выберите цифру:

- **1 — установить или продолжить настройку.**
- **2 — полная переустановка с нуля.**
- **3 — проверить подключение Codex и проекта.**
- **0 — выход.**

Мастер сам находит доступные настройки проекта и обычного профиля Codex, показывает папку и точный объём доступа. Для нового проекта: **1 — разрешить**, **2 — подробности**, **0 — пропустить**. Затем проверьте свой аккаунт Codex. Вводить пути и команды вручную не требуется; если готового проекта или совместимого Codex нет, мастер честно показывает незавершённый шаг. Зависимости и скрытые разрешения автоматически не добавляются.

Уже подключённый точный 0.8.30 поддерживается без замены действующего EXE, повторной привязки и полной переустановки; допустимый SHA256 указан в манифесте. Устройство, аккаунт, файлы, права и автозапуск сохраняются. Активные и неопределённые задачи принудительно не завершаются. После подтверждения обычного профиля ChatGPT может по входящему запросу читать список задач и локальный архив, открывать и продолжать существующие задачи в разрешённой рабочей папке.

CMD получил абзацы, отступы, значки и цифровое меню. При остановке рядом с ним автоматически сохраняется `Hvost-Install-Report-….txt` с этапами и кодом — без паролей, кода привязки и содержимого задач. Команды PowerShell для диагностики вводить не нужно.

Ручной тестовый preview **без подписи издателя**. CMD проверяет HTTPS, размер и SHA256; SHA256 подтверждает байты, а не издателя. Автоматическая замена неподписанного клиента остаётся закрытой; настройки UAC и антивируса не меняются. Клиент запускается после входа в Windows; работа до входа, полная приёмка Windows/Linux и совместимость с антивирусами ещё не завершены. Приостановленные выпуски не устанавливайте.
