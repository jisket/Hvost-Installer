# Хвост — установщик для Windows

Клиент для управления своим компьютером через кабинет Хвоста. Это тестовый выпуск **0.8.5-alpha.1**, без подписи издателя.

## Уже есть компьютер в кабинете

1. Откройте [кабинет → Компьютеры](https://hvost.46-188-16-161.sslip.io/#devices) и нужную прежнюю запись. При одинаковых именах сверяйте ID и последнее соединение.
2. Нажмите **Переподключить** либо **Изменить права**, выберите инструменты и получите код.
3. Скачайте только [Hvost-Reconnect.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.5-alpha.1-pilot.20261107/Hvost-Reconnect.cmd) и запустите на этом компьютере. EXE загрузится автоматически и пройдёт проверку размера и SHA256.
4. Вставьте код с сайта, проверьте устройство, папки и права. Лично введите показанную строку **RESTORE**. Закройте прежнее окно управления, если оно открыто.

Клиент использует прежнюю папку, если сохранилась его проверенная запись автозапуска. История, ID устройства и данные сохраняются. Старые profile/workspace не удаляйте. Новый набор прав действует после подтверждения на ПК; до этого сохраняется прежний доступ.

Можно выбирать изменение файлов, терминал и процессы, экран/буфер обмена, браузер и AI-задачи. Чтение необходимо для базовых инструментов. Запущенные программы и Codex/Claude имеют права пользователя Windows; эти переключатели не создают изоляцию процессов. Точный доступ и папки показаны в локальном мастере.

## Новый компьютер

Скачайте [Hvost-Install.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.5-alpha.1-pilot.20261107/Hvost-Install.cmd). Скрипт скачает клиент, откроет кабинет для регистрации/входа и запросит одноразовый код подключения. Начальный доступ ограничен файлами в workspace. Права затем выбираются в карточке этого ПК.

## Управление клиентом

После подключения окно CMD можно закрыть. Один фоновый клиент запускается после вашего входа в Windows. Ярлык **Хвост** на рабочем столе позволяет проверить связь, запустить или остановить клиент, управлять автозапуском и удалить программу с сохранением данных.

[Все файлы и контрольные суммы выпуска](https://github.com/jisket/Hvost-Installer/releases/tag/v0.8.5-alpha.1-pilot.20261107).

Проверка новым Kaspersky и подпись издателя пока не подтверждены. Не отключайте антивирус, не добавляйте исключения и не передавайте пароль или код восстановления в переписке. Сервер, исходники закрытого проекта, пароли и ключи аккаунтов в этом репозитории не публикуются. Linux и полноценный публичный релиз проходят отдельную приёмку.
