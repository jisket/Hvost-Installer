# Хвост — тестовый установщик Windows

Актуальный ручной тестовый выпуск: **0.8.26-alpha.1**.

[Скачать один Hvost-Install.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.26-alpha.1-pilot.20261111/Hvost-Install.cmd) и открыть его. Остальные файлы загружаются автоматически, подтверждения вводятся цифрами.

## Выберите действие

- **1 — установить или открыть клиент.** Новая установка использует системный диск и создаёт ярлык «Хвост».
- **2 — полная переустановка с нуля.** Активные Client и служебные профили убираются; старые файлы и журналы сохраняются в `%LOCALAPPDATA%\Hvost-Backups`. Затем создаётся новый профиль.
- **3 — подключить или исправить Codex.** Для уже подключённого 0.8.25 меняется только настройка Codex, а прежние EXE клиента, устройство, аккаунт, папки и права сохраняются.
- **0 — отмена.**

Для пункта 3 закройте другие окна управления «Хвостом». Мастер сам выберет установленный Codex и прежнюю рабочую папку; проверьте программу, затем аккаунт и подтвердите цифрой **1**. Если Codex не подтвердил вход, откройте обычный Codex на этом ПК, проверьте вход и повторите пункт 3. Повторный код подключения ПК для этого действия не требуется.

Для новой установки войдите в свой существующий аккаунт в открывшемся кабинете, выберите «Подключить компьютер» и введите выданный код в установщике. Windows отдельно запросит права администратора; это личное подтверждение Windows.

После локального подключения профиля ChatGPT по запросу может читать свежий список задач, включая локальный архив, и продолжать выбранную задачу по исходному ID в разрешённой папке. Настройка сама модель не запускает. Фоновый клиент работает без постоянного CMD; автозапуск — после входа в Windows.

## Если действие остановилось

Рядом с CMD с первого шага создаётся `Hvost-Install-Report-….txt`. Передайте этот файл для разбора: он содержит этап, итог и короткий код ошибки. Пароли, коды привязки, token и личные беседы не записываются. После внезапного закрытия может остаться последний этап без окончательного результата. Отдельные команды PowerShell не нужны.

## Статус

Чистая установка, привязка и команды на втором ПК подтверждены для 0.8.25. Для нового пути 3 проверены изолированный полный сценарий с прежними правами, сохранение worker/identity/data/admin, отмена, гонка серверного выбора и lost/unknown ответы без replay. Физическая приёмка пути 3 и полная задача Codex ещё предстоят.

Это тестовый выпуск без подписи издателя. SHA256 проверяет соответствие байтов опубликованному CMD, но не удостоверяет издателя. Неподписанное автообновление не включено. Защиту оставьте включённой. Полный Windows/Linux релиз ещё не принят.
