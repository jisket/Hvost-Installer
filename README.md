# Хвост — установщик Windows


[Новое подключение — скачать один CMD](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.4-alpha.2-pilot.20261107/Hvost-Install.cmd)


[Обновить уже подключённый тестовый ПК — Hvost-Control.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.4-alpha.2-pilot.20261107/Hvost-Control.cmd)


## Уже подключённый тестовый ПК


1. Закройте окно управления «Хвост», если оно открыто. Старое CMD прежнего клиента также закройте. Фоновый клиент будет штатно остановлен самим установщиком после вашего подтверждения.
2. Сохраните Hvost-Control.cmd в прежнюю папку рядом с profile и workspace.
3. Запустите именно Hvost-Control.cmd, просмотрите разрешения и лично введите целиком показанную строку FULL с кодом. Новый аккаунт и новый код привязки не нужны.

Ответ «д/Н» в обычном Hvost-Install.cmd включает только файловый режим. Для перехода используйте ссылку Hvost-Control.cmd выше. Существующие аккаунт, устройство и данные сохраняются.


Расширенный режим требует разрешения владельца на сервере. Он работает в пределах прав текущего пользователя Windows: файлы, терминал/процессы, окна и буфер обмена, поддерживаемый браузер, обнаруженные Codex/Claude. Права администратора не выдаются. Провайдеры требуют отдельной установки и входа.


## Новое подключение


1. Сохраните Hvost-Install.cmd в отдельную обычную папку и запустите двойным щелчком. EXE скачивается и проверяется автоматически.
2. Подтвердите показанную папку и фоновый запуск. В открывшемся браузере войдите или зарегистрируйтесь.
3. Выберите «Компьютеры → Подключить компьютер» и вставьте 16-символьный код в CMD. Код входа в кабинет для этого не подходит.


Новый обычный профиль имеет только чтение и запись в workspace. Второй ПК существующего тестового владельца подключается к прежнему аккаунту; новый аккаунт получает отдельный бесплатный тариф.


## Управление без постоянной консоли


После установки CMD можно закрыть. Работает один фоновый клиент с автозапуском после входа в Windows. Ярлык **Хвост** на рабочем столе открывает проверку соединения, запуск/остановку, настройку автозапуска, рабочую папку, кабинет, диагностику и удаление клиента.


Закрытие окна управления сохраняет связь. «Остановить» отключает клиент до явного запуска. «Удалить клиент» удаляет его EXE, ярлык и автозапуск, сохраняя profile, workspace, файлы и привязку. Аккаунт на сайте не удаляется. Сохраните папки profile, workspace и .hvost-client; не переносите их при работающем клиенте.
