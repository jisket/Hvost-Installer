# Хвост — тестовый установщик Windows

Актуальный ручной тестовый выпуск: **0.8.25-alpha.1**.

## Установить на свой компьютер

1. [Скачайте Hvost-Install.cmd](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.25-alpha.1-pilot.20261111/Hvost-Install.cmd) и откройте его. EXE загружается автоматически.
2. Выберите **1 — установить или открыть клиент** либо **2 — полная переустановка с нуля**. **0 — отмена**. Вводить слова для подтверждения не требуется.
3. Просмотрите права и выберите **1 — подключить**. Windows отдельно запросит права администратора; отказ оставляет обычное управление.
4. В открывшемся кабинете войдите в свой существующий аккаунт и выберите «Подключить компьютер». Введите выданный код в установщике. Новый аккаунт для второго ПК не требуется.
5. Если найден установленный Codex с выполненным входом, проверьте показанный аккаунт и папку. **1 — подключить задачи**, **0 — пропустить**.

Клиент устанавливается на системный диск и создаёт ярлык «Хвост». После подключения работает в фоне без постоянного CMD; автозапуск — после входа в Windows. ChatGPT по запросу может получать свежий список разрешённого локального профиля Codex, включая архив, и продолжать выбранную задачу по исходному ID в разрешённой папке.

## Полная переустановка

Пункт **2** сначала убирает прежние активные Client и служебные профили, их автозапуск, ярлык и незавершённые журналы. Старые файлы переносятся в `%LOCALAPPDATA%\Hvost-Backups`. Затем начинается новая установка в `%LOCALAPPDATA%\Hvost\Client` с пустым профилем. Профиль Codex и сторонние приложения не очищаются. Аккаунт и прежняя карточка компьютера на сервере не удаляются.

## Если установка остановилась

Рядом с CMD с первого шага создаётся `Hvost-Install-Report-….txt`. Передайте этот файл для разбора: он сохраняет этап, итог и короткий код ошибки. Коды привязки, пароли и token туда не записываются. После внезапного закрытия в файле может остаться последний этап без окончательного результата. Отдельные команды PowerShell не нужны.

## Статус тестирования

Для 0.8.25 проверен изолированный цельный сценарий полной очистки и новой привязки, сохранение файлов, отмена, изменение автозапуска и ошибка после очистки. Реальные CMD/PowerShell 5.1 сохраняют отчёт до загрузки и останавливают запуск без локального подтверждения. Входящий список и продолжение задачи Codex ранее проверены на 0.8.23. Физическая приёмка 0.8.25 на втором ПК с включённым антивирусом ещё предстоит.

Это тестовая версия без подписи издателя. SHA256 проверяет соответствие байтов опубликованному CMD, но не удостоверяет издателя. Неподписанное автообновление не включено. Оставьте антивирус включённым. Полный релиз Windows/Linux ещё не принят.
