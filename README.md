# Хвост — установщик Windows

[Скачать Hvost-Install.cmd 0.8.28](https://github.com/jisket/Hvost-Installer/releases/download/v0.8.28-alpha.1-pilot.20261111/Hvost-Install.cmd) · [Файлы выпуска](https://github.com/jisket/Hvost-Installer/releases/tag/v0.8.28-alpha.1-pilot.20261111)

Откройте CMD и выберите **1** установить/открыть, **2** полностью переустановить, **3** подключить или исправить Codex, **0** отменить. Подтверждения — цифрами.

Версия0.8.28 поддерживает Codex0.167.0-alpha.4.1. Для уже подключённого0.8.25 пункт3 при необходимости предлагает отдельный личный обзор ручного обновления клиента с сохранением устройства, аккаунта, конфигурации, файлов, проектов, прав и автозапуска. Старый EXE сохраняется; переустановка и повторная привязка не нужны. Затем просмотрите свой аккаунт Codex и подключите задачи.

Свободное окно управления закрывается штатно; активные/неопределённые задачи не завершаются принудительно. При ошибке рядом с CMD остаётся Hvost-Install-Report-….txt.

Ручной тестовый preview **без подписи издателя**. CMD проверяет HTTPS, размер и SHA256; SHA256 не удостоверяет издателя. Автоматическая замена неподписанного клиента остаётся закрытой; UAC и антивирус не изменяются. Полный релиз Windows/Linux, работа до входа и окончательная приёмка второго ПК ещё не завершены. Приостановленный0.8.11 не устанавливайте.
